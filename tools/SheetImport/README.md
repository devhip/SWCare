# SheetImport — นำเข้าข้อมูลเดิมจาก Tab "แจ้งงาน"

ใช้ครั้งเดียวตอนเปิดระบบ (แผนข้อ 12) นำ 71 รายการจาก Google Sheet เข้าเป็นงานใน SWCare

## ก่อนนำเข้า

1. ติดตั้ง API และ migrate ฐานข้อมูลแล้ว (`docs/Deploy.md`)
2. **สร้างบัญชีผู้ใช้จริงให้ครบก่อน** — ชื่อในชีตจะจับคู่กับบัญชีตาม username, อีเมล, ส่วนหน้า @ ของอีเมล หรือชื่อที่แสดง
3. ตั้งผู้รับผิดชอบหลักของแต่ละระบบ (Admin → ข้อมูลหลัก) — งานที่ "กำลังแก้ไข" จะไปอยู่กับคนนี้
4. Google Sheet → ไฟล์ → ดาวน์โหลด → **CSV** (ขณะเปิด Tab "แจ้งงาน") ไฟล์นี้มีข้อมูลลูกค้า **ห้าม commit**

## ขั้นตอน

```powershell
cd E:\API_Dotnet\SWCare
$env:ConnectionStrings__SWCare = "Server=<server>;Database=SWCare;Trusted_Connection=True;TrustServerCertificate=True"

# 1) ดูรายงานก่อน (ไม่บันทึกอะไร)
dotnet run --project tools/SheetImport -- --csv C:\import\แจ้งงาน.csv

# 2) ชื่อที่จับคู่ไม่ได้ / ประเภทที่เดาผิด → copy import-map.example.json เป็น import-map.json แล้วแก้ จากนั้นรันข้อ 1 ซ้ำพร้อม --map
dotnet run --project tools/SheetImport -- --csv C:\import\แจ้งงาน.csv --map C:\import\import-map.json

# 3) บันทึกจริง
dotnet run --project tools/SheetImport -- --csv C:\import\แจ้งงาน.csv --map C:\import\import-map.json --apply
```

บันทึกทั้งหมดในครั้งเดียว (ถ้าพังกลางทางจะไม่มีงานไหนถูกบันทึก) และรันซ้ำไม่ได้ถ้าฐานข้อมูลมีงานที่นำเข้าแล้ว (ต้องใส่ `--force`)

## นำเข้าเป็นอะไร

| ชีต | SWCare |
|---|---|
| ปิดงาน | ปิดงาน ใช้วันที่ตามชีต |
| แจ้งงาน + มีวันเริ่มแก้ไข | กำลังแก้ไข — คนทำ = "แก้ไขโดย" ถ้าจับคู่ได้ ไม่งั้นผู้รับผิดชอบหลักของระบบ (ถ้าระบบไม่มีผู้รับผิดชอบหลัก → รอจัดคิว) |
| แจ้งงาน | รอจัดคิว (ไม่ต้องอนุมัติอีก) |
| แถวว่าง (Id 34) | ไม่นำเข้า |

- เลขที่งาน `SW-<ปีของวันที่แจ้ง>-NNNN` ตามลำดับ Id ในชีต · เลข QP/RQ เก็บใน "เลขอ้างอิงเดิม" (ค้นหาได้)
- หัวข้อ = บรรทัดแรกของรายละเอียด · ลูกค้า = ข้อความในวงเล็บหลังชื่อระบบ เช่น `HIP EasyPark (ซีเลสเซียล)`
- ระบบ: จับคู่ชื่อที่พิมพ์ต่างกันตามแผนข้อ 6.2 ที่เหลือเป็น "อื่นๆ" · รุ่นเครื่อง: หาชื่อรุ่นในข้อความ
- ประเภทงาน: เดาจากคำ (D7) — "ทดสอบ…" = ทดสอบ, มีคำว่า "ไม่ได้ / error / ค้าง…" = Bug, "ลบ/นำเข้า/ย้ายข้อมูล" = บริการข้อมูล, "เพิ่มรุ่น/ขอเพิ่ม/เปลี่ยน logo" = ขอเพิ่มฟีเจอร์ ที่เหลือ = Bug
- ชื่อคนที่จับคู่ไม่ได้เก็บเป็นข้อความและแสดงในหน้างาน ถ้าคนแจ้งไม่มีบัญชี ระบบใช้บัญชี `--fallback-user` (ค่าเริ่มต้น `admin`) แทนแต่แสดงชื่อจากชีต
- ติดธง **"ข้อมูลเดิมต้องตรวจ"** เมื่อ: วันที่ผิดรูปแบบ (เช่นปี `226`), วันเริ่มก่อนวันแจ้ง, วันเสร็จก่อนวันเริ่ม, Dead line ก่อนวันแจ้ง, การแก้ไขเขียนว่า "ยังไม่ได้แก้ไข", ไม่มีชื่อระบบ — เหตุผลอยู่ใน Timeline ของงาน
- ไม่ส่งแจ้งเตือน และไม่ต้องมี "สิ่งที่ทดสอบแล้ว"
