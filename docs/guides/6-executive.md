# ผู้บริหาร

ดูภาพรวมงานที่แจ้งถึงโปรแกรมเมอร์ทั้งบริษัท — เข้าระบบแล้วจะเปิดหน้า **Dashboard** ให้เลย

สิทธิ์ผู้บริหารให้ Admin เปิดที่หน้า **ผู้ใช้** (สวิตช์ "ผู้บริหาร")

## Dashboard

ด้านบนเลือก **ช่วงวันที่** (3 / 6 / 12 เดือนล่าสุด, ปีนี้, ปีที่แล้ว หรือกำหนดเอง), **แผนก** และ **ระบบ/โปรแกรม**

| ส่วน | ดูอะไร |
|---|---|
| ตัวเลขสรุป | งานค้างตอนนี้ · เลยกำหนดตอนนี้ · งานเข้าใหม่ · ปิดงานได้ · % เสร็จทันกำหนด · เฉลี่ยกี่วันตั้งแต่แจ้งจนปิด |
| แนวโน้มรายเดือน | งานเข้าเทียบงานที่ปิดได้ แต่ละเดือน — ถ้างานเข้ามากกว่าปิดต่อเนื่อง แปลว่างานค้างสะสม (กด "ดูเป็นตาราง" เพื่อดูตัวเลข) |
| งานค้างแยกสถานะ | ตอนนี้งานติดอยู่ขั้นไหนมากที่สุด |
| แยกตามระบบ / ประเภท / แผนก / ลูกค้า | ระบบไหนมีปัญหาบ่อย ลูกค้าไหนแจ้งมาก แผนกไหนแจ้งมาก |
| เวลาเฉลี่ยแต่ละขั้น | รออนุมัติ → รอจัดคิว → อยู่ในคิว → กำลังแก้ไข → รอปิด ขั้นไหนช้า |
| ทีมโปรแกรมเมอร์ | งานในมือ, เลยกำหนด, จบงานในช่วง, เฉลี่ยวันแก้ไข, จำนวนครั้งที่เลื่อนวัน ของแต่ละคน |
| ไม่ดำเนินการ แยกตามแผนก | งานที่ไม่ใช่ปัญหาโปรแกรม มาจากแผนกไหน พร้อมเหตุผลล่าสุด |

ชี้เมาส์ที่แท่งกราฟเพื่อดูตัวเลข · ปุ่ม **Export Excel** ได้ไฟล์ตามตัวกรองที่เลือก (แผ่นสรุป + รายการงานในช่วง)

## ดูรายละเอียดงาน

**รายงานทั้งหมด** — เห็นทุกงาน ค้นหาด้วยเลขที่ หัวข้อ ลูกค้า ได้ เปิดดูรายละเอียด Timeline และคอมเมนต์ได้ แต่ **อ่านอย่างเดียว** (ไม่มีปุ่มทำรายการ) · อยากรู้ความคืบหน้างานไหน กด **ติดตามงานนี้** ในช่องผู้ติดตาม จะได้แจ้งเตือนและคอมเมนต์ในงานนั้นได้ ถ้าต้องการให้ทีมทำอะไรเพิ่ม แจ้งผ่านหัวหน้าแผนกหรือสร้างงานใหม่
