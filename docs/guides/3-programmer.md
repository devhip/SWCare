# โปรแกรมเมอร์

คุณเห็นงานทั้งหมด งานของคุณอยู่ที่ **งานของฉัน → ที่ต้องทำ** และแถวของคุณใน **Kanban**

## ทำงาน

| ต้องการ | ในหน้างาน | ใน Kanban |
|---|---|---|
| เริ่มทำ | **เริ่มแก้ไข** | ลากการ์ดจาก "อยู่ในคิว" ไป "กำลังแก้ไข" |
| หยุดไว้ก่อน (มีงานด่วนแทรก) | **พักงาน** — กลับเข้าคิว | ลากกลับไป "อยู่ในคิว" |
| ถามคนแจ้ง | **ขอข้อมูลเพิ่ม** (บอกว่าต้องการอะไร) | ลากไป "รอข้อมูลเพิ่ม" |
| เสร็จ | **จบงาน** — ต้องกรอก **การแก้ไข** | ลากไป "จบงาน (รอปิด)" |
| ทำไม่ทันวันที่วางไว้ | **เลื่อนวัน** — ใส่วันใหม่และเหตุผล | — |

- ทำตามลำดับคิวในแถวของคุณ (หัวหน้าโปรแกรมเมอร์เป็นคนเรียง)
- **การแก้ไข** เขียนให้ Support อ่านแล้วไปบอกลูกค้าได้: แก้อะไร เวอร์ชันไหน ต้องทำอะไรที่หน้างาน
- ระหว่างทำ คุยกับคนแจ้งในคอมเมนต์ได้ แนบไฟล์ได้ (เช่น ตัวติดตั้ง ≤ 20 MB หรือลิงก์ Drive)
- ถ้าคนแจ้ง **ส่งกลับ** งานกลับมา "กำลังแก้ไข" พร้อมเหตุผลใน Timeline

## แจ้งเตือนที่จะได้

ได้รับงานใหม่ / ถูกเปลี่ยนคนทำ · คนแจ้งตอบข้อมูลที่ขอ · คนแจ้งส่งกลับ · งานของคุณถูกปิดหรือยกเลิก · คอมเมนต์ในงานของคุณ · งานเลยวันคาดว่าจะเสร็จ (ทุกเช้าวันทำการ)
