## ใช้ได้ทุกคน

- **เข้าครั้งแรก**: ใช้ชื่อผู้ใช้และรหัสที่ Admin ให้ ระบบจะให้เปลี่ยนรหัสทันที (8–64 ตัวอักษร ห้ามเหมือนชื่อผู้ใช้) · ลืมรหัส → ให้ Admin ตั้งใหม่
- **กระดิ่ง** มุมขวาบน: แจ้งเตือนทุกอย่างที่เกี่ยวกับคุณ อัปเดตทุก 1 นาที กดแล้วไปที่งานนั้น
- **งานของฉัน**: หน้าแรกหลัง login แยกแท็บ ที่ต้องทำ / ที่ต้องอนุมัติ / ที่รอฉันปิด / ที่ฉันแจ้ง / ที่ร้องขอ-ติดตาม — ตัวเลขข้างแท็บคืองานที่ค้าง
- **รายงานทั้งหมด**: ค้นหาด้วยเลขที่ (`SW-2026-0001` หรือเลข QP/RQ เดิม), หัวข้อ, รายละเอียด, การแก้ไข, ชื่อลูกค้า — เห็นเฉพาะงานที่เกี่ยวกับคุณ ถ้าต้องค้นประวัติงานทุกงาน (เช่นเซลล์ที่ลูกค้าโทรมาถาม) ขอ Admin เปิดสิทธิ์ **ดูงานทั้งหมด**
- **ติดตามงานนี้**: ปุ่มในช่องผู้ติดตามของหน้างาน กดแล้วได้แจ้งเตือนทุกความคืบหน้าและคอมเมนต์ได้ งานไปอยู่ในแท็บ ที่ร้องขอ-ติดตาม · กด **เลิกติดตาม** เมื่อไม่ต้องการแล้ว
- **Dashboard** (ผู้บริหาร, หัวหน้าแผนก, หัวหน้า Support, หัวหน้าโปรแกรมเมอร์, Admin): ภาพรวมงานและ Export Excel — หัวหน้าแผนกเห็นเฉพาะแผนกตัวเอง รายละเอียดใน [คู่มือผู้บริหาร](6-executive.md)
- **TH / EN** มุมขวาบนเปลี่ยนภาษา ระบบจำไว้ให้
- งานที่จบแล้ว (ปิดงาน / ยกเลิก / ไม่ดำเนินการ) เปิดใหม่ไม่ได้ — ถ้าปัญหากลับมาให้สร้างงานใหม่แล้วอ้างเลขงานเดิมในรายละเอียด
- งานที่นำเข้าจากชีตเดิมมีป้าย **ข้อมูลเดิมต้องตรวจ** เมื่อวันที่หรือข้อมูลในชีตขัดกัน ดูเหตุผลใน Timeline

## ขั้นตอนของงาน

```text
สร้างงาน → รออนุมัติ → รอจัดคิว → อยู่ในคิว → กำลังแก้ไข → จบงาน (รอปิด) → ปิดงาน
             │ ตีกลับ (แก้แล้วส่งใหม่)        ↑ พักงาน ↓        │ ส่งกลับให้โปรแกรมเมอร์
             └─ หัวหน้าแผนกแจ้งเอง = ข้ามขั้นอนุมัติ               └─ ไม่มีใครปิด 3 วันทำการ = ระบบปิดเอง
รอข้อมูลเพิ่ม: โปรแกรมเมอร์ถามคนแจ้ง → ตอบในคอมเมนต์แล้วงานกลับไปขั้นเดิมเอง
```
