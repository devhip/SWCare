# หัวหน้าโปรแกรมเมอร์

คุณจัดคิวงานทั้งหมดให้ทีม และทำงานเองได้เหมือนโปรแกรมเมอร์ ([คู่มือโปรแกรมเมอร์](3-programmer.md))

## จัดคิว — เมนู "รอจัดคิว"

งานที่อนุมัติแล้ว เรียง "ทำทันที" ไว้บนสุด ตัวเลขข้างเมนูคืองานที่รอ

| ทำ | ปุ่ม | กรอก |
|---|---|---|
| รับงาน | **จัดคิว** | ความเร่งด่วนจริง, คนทำ (ระบบเสนอผู้รับผิดชอบหลักของระบบนั้น), วันวางแผนเริ่ม, วันคาดว่าจะเสร็จ (ระบบเดาจากความเร่งด่วน) · แก้ประเภทงาน/ระบบที่คนแจ้งเลือกผิดได้ในขั้นนี้ |
| ข้อมูลไม่พอ | **ขอข้อมูลเพิ่ม** | ต้องการอะไร |
| ไม่รับ (ไม่ใช่ปัญหาโปรแกรม, แก้ที่หน้างานได้, firmware) | **ไม่ดำเนินการ** | เหตุผล — ทำได้ทุกขั้นจนก่อนจบงาน |

## Kanban

- แถว = โปรแกรมเมอร์แต่ละคน + แถว **ยังไม่จัดคิว** · คอลัมน์ = สถานะ
- **ลากขึ้นลงในคอลัมน์ "อยู่ในคิว"** = เรียงลำดับคิวของคนนั้น
- **ลากไปแถวคนอื่น** = เปลี่ยนคนทำ
- **ลากจาก "ยังไม่จัดคิว" ไปแถวของใคร** = เปิดกล่องจัดคิวพร้อมเลือกคนนั้นไว้
- ย้ายผิดขั้นตอน ระบบจะแจ้งว่า "ย้ายแบบนี้ไม่ได้"

## Dashboard

เมนู **Dashboard** เห็นทุกฝ่าย: ภาระงานแต่ละคน, งานเลยกำหนด, จำนวนครั้งที่เลื่อนวัน, เวลาแต่ละขั้น และงานที่ไม่ดำเนินการแยกตามฝ่าย ([คู่มือผู้บริหาร](6-executive.md))

## ระหว่างทำ

- **เปลี่ยนคนทำ**, **เลื่อนวัน**, **พักงาน** ได้ทุกงานที่จัดคิวแล้ว (เลื่อนวันต้องใส่เหตุผล เก็บประวัติไว้)
- เพิ่มผู้ติดตามได้ทุกงาน
- แจ้งเตือนที่จะได้: งานที่อนุมัติแล้วรอจัดคิว · คนแจ้งตอบข้อมูล (งานที่ยังไม่มีคนทำ) · คนแจ้งส่งกลับ · โปรแกรมเมอร์เลื่อนวันเอง · งานที่จัดคิวแล้วถูกยกเลิก · งานเลยกำหนด (ทุกเช้าวันทำการ)
- ตั้งผู้รับผิดชอบหลักของแต่ละระบบ: ขอ Admin แก้ที่ **ข้อมูลหลัก**
