# คนแจ้งงาน (Support, Sale, Product)

## แจ้งงาน — เมนู "สร้างงาน"

| ช่อง | กรอกอย่างไร |
|---|---|
| หัวข้อ | สั้นๆ ให้อ่านในรายการแล้วรู้เรื่อง เช่น "นำเข้ารายชื่อ Excel ไม่ได้" |
| ประเภทงาน | Bug · ขอเพิ่มฟีเจอร์/รุ่นเครื่อง · ทดสอบ/R&D · งานบริการข้อมูล |
| ระบบ/โปรแกรม | เลือกจากรายการ ไม่มีให้เลือก "อื่นๆ" |
| เวอร์ชัน, รุ่นเครื่อง, ลูกค้า/หน้างาน | ใส่ถ้ารู้ — ชื่อลูกค้าระบบจะแนะนำจากงานก่อนๆ |
| รายละเอียดที่แจ้ง/ปัญหา | อาการ, ขั้นตอนทำให้เกิด, ข้อความ Error |
| **สิ่งที่ทดสอบแล้ว** | **Customer Support ต้องกรอกเมื่อเป็น Bug หรือขอเพิ่มฟีเจอร์/รุ่นเครื่อง** — เติมใต้หัวข้อที่ระบบใส่ไว้ให้ |
| ความเร่งด่วน | ทำทันที / ด่วน (1–2 วัน) / ปกติ (ตามคิว) — หัวหน้าโปรแกรมเมอร์อาจปรับตามคิวจริง |
| ผู้ร้องขอ | ถ้าแจ้งแทนคนอื่น เช่น เซลล์ เลือกชื่อเขา เขาจะได้แจ้งเตือนทุกขั้น |
| ผู้ติดตาม | คนอื่นที่อยากให้รู้ความคืบหน้า |
| ไฟล์แนบ | รูป, PDF, Excel, Word, zip, วิดีโอสั้น, txt/log ครั้งละ 10 ไฟล์ ไฟล์ละไม่เกิน 20 MB · log ใหญ่ให้แนบลิงก์ Google Drive |

กด **ส่ง** → งานไป "รออนุมัติ" ที่หัวหน้าฝ่ายของคุณ (ถ้าคุณเป็นหัวหน้าฝ่ายเอง ไป "รอจัดคิว" เลย)

## ระหว่างรอ

- **ตีกลับ**: หัวหน้าฝ่ายให้แก้ อ่านเหตุผลใน Timeline → **แก้ไข** → **ส่งใหม่**
- **รอข้อมูลเพิ่ม**: โปรแกรมเมอร์ถาม → ตอบในช่อง **คอมเมนต์** (แนบไฟล์ได้) งานกลับไปทำต่อเอง
- **คอมเมนต์** คุยกับโปรแกรมเมอร์ได้ทุกขั้น
- **ยกเลิกงาน**: ทำได้จนกว่าโปรแกรมเมอร์จะเริ่มแก้ไข ต้องใส่เหตุผล
- ดูความคืบหน้า: สถานะ, คนทำ, วันคาดว่าจะเสร็จ, Timeline ในหน้างาน

## เมื่อโปรแกรมเมอร์จบงาน — "จบงาน (รอปิด)"

1. อ่าน **การแก้ไข** ในหน้างาน แล้วตรวจกับลูกค้า / หน้างาน
2. ใช้ได้ → **ปิดงาน**
3. ยังไม่ได้ → **ส่งกลับให้โปรแกรมเมอร์** พร้อมเหตุผล

ถ้าไม่ปิดภายใน **3 วันทำการ** ระบบปิดให้เอง (เตือนก่อน 1 วัน) งานรอปิดอยู่ในแท็บ **ที่รอฉันปิด**
