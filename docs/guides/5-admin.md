# Admin

เมนูหมวด **Admin** (เห็นเฉพาะ Admin) ไม่มีการลบข้อมูลในระบบ — ใช้ปิดใช้งานแทน

## ผู้ใช้

- **เพิ่มผู้ใช้**: ชื่อผู้ใช้ (a-z 0-9 . - _ เปลี่ยนภายหลังไม่ได้), ชื่อที่แสดง, อีเมลบริษัท, แผนก, รหัสผ่านเริ่มต้น → ผู้ใช้ต้องเปลี่ยนรหัสตอน login ครั้งแรก
- **บทบาทมาจากแผนก**: อยู่แผนก Software = โปรแกรมเมอร์, หัวหน้าแผนก Software = หัวหน้าโปรแกรมเมอร์, หัวหน้าแผนก Customer Support = หัวหน้า Support · เปลี่ยนแล้วมีผลทันที
- **สิทธิ์ Admin**, **ผู้บริหาร** (Dashboard ทั้งบริษัท + ดูงานทุกงานแบบอ่านอย่างเดียว) และ **ดูงานทั้งหมด** (ค้นหาและเปิดดูทุกงานแบบอ่านอย่างเดียว ไม่มี Dashboard — เช่นเซลล์ที่ต้องดูประวัติงานของลูกค้า) เปิดในหน้าแก้ไขผู้ใช้
- **คนลาออก**: ปิด "ใช้งาน" — งานเดิมยังอยู่ครบ (ถ้าเป็นหัวหน้าแผนกต้องตั้งหัวหน้าใหม่ก่อน)
- **ลืมรหัส**: แก้ไขผู้ใช้ → **ตั้งรหัสผ่านใหม่** → ผู้ใช้ต้องเปลี่ยนอีกครั้ง และ session อื่นของเขาหลุดทั้งหมด

## แผนก

- ทุกแผนกต้องมีหัวหน้า (คนอนุมัติงานของแผนก) — เลือกได้เฉพาะสมาชิกของแผนกที่ยังใช้งาน
- สร้างแผนกใหม่ → ย้ายคนเข้าแผนกที่หน้า **ผู้ใช้** → กลับมาตั้งหัวหน้า

## ข้อมูลหลัก

- **ระบบ/โปรแกรม**: ชื่อ, **ผู้รับผิดชอบหลัก** (โปรแกรมเมอร์ที่ระบบเสนอตอนจัดคิว), ลำดับ, ใช้งาน
- **รุ่นเครื่อง**: เพิ่มเมื่อมีรุ่นใหม่
- **ตั้งค่า**: จำนวนวันทำการก่อนปิดงานอัตโนมัติ (3), เวลาแจ้งเตือนรอบเช้า (08:30), หัวข้อในช่อง "สิ่งที่ทดสอบแล้ว"

## เปิดระบบครั้งแรก

ตามลำดับ: เปลี่ยนรหัส `admin` → ตั้งชื่อแผนก → สร้างผู้ใช้ทุกคน → ตั้งหัวหน้าแผนก → ตั้งผู้รับผิดชอบหลักของระบบ → นำเข้าข้อมูลเดิม (`docs/Deploy.md` ข้อ 7) → แจ้งทุกคนให้ login และเปลี่ยนรหัส

การติดตั้ง อัปเดต และสำรองข้อมูล: `docs/Deploy.md`
